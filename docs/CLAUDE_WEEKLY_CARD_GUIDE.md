# Claude 周卡开通与使用教程

正式环境已更新至 `2.8.13-monas-claude-weekly.2`，可以手动开卡。固定选择 **Claude 周卡 · 独立额度** 分组。
首次服务器配置和分组启用已经完成，日常开卡直接从用户管理开始。

## 管理员给用户开卡

1. 打开 [用户管理](https://sub2api.monasapi.com/admin/users)，搜索用户邮箱。
2. 在该用户行点击 **更多 → 管理 Claude 周卡**。
3. 分组选择 **Claude 周卡 · 独立额度**；处理方式选择 **开通周卡**。
4. 套餐保持 **手动填写额度**，在 **当期额度（USD）** 填入要给这位用户的使用额度，例如 `100`。这不是销售价格，也不会充值到普通余额；每位用户可以填写不同额度。
5. 点击 **预览排期**，核对额度和时间，再点击 **确认开卡**。
6. 看到 **周卡已保存** 和卡片 **使用中** 才算成功。有效期从服务器实际开卡时间起算，固定 168 小时。

现在不需要新建分组、进入维护或配置套餐。左侧的“拼车管理 / 拼车月卡”是原有业务；本功能的日常入口是上面的“管理 Claude 周卡”。

## 用户使用这张卡

1. 用户登录后打开 [我的订阅](https://sub2api.monasapi.com/subscriptions)，确认 **Claude 周卡 · 独立额度** 显示使用中、额度和到期时间。
2. 打开 [API 密钥](https://sub2api.monasapi.com/keys)，点击 **创建密钥**，厂商选择 **Anthropic**，分组选择 **Claude 周卡 · 独立额度**，填写名称后创建。
3. 在新 Key 行点击 **使用密钥**，按页面的 **Claude Code / macOS / Windows** 指引配置客户端。服务地址是 `https://sub2api.monasapi.com`，使用的是该用户自己的新 Key。
4. 使用后打开现有 [使用记录](https://sub2api.monasapi.com/usage)，分组筛选 **Claude 周卡 · 独立额度**，按需选择 Key 和时间范围，即可查看模型、Token、费用与汇总统计。记录按页加载；“我的订阅”只看额度、有效期和卡期历史。

已经存在的 Key 不会自动换组。仍绑定 **claude-kiro渠道-无缓存-周卡** 的旧 Key，继续使用原来的余额计费；要使用新周卡，创建绑定 **Claude 周卡 · 独立额度** 的 Key，或在 Key 行选择该新分组。建议先创建新 Key 验证，再按需切换客户端。

同一用户在该分组下的多个 Key 共用同一张卡。Claude 默认并发为 3，与 GPT 并发独立。创建 Key 时的“额度限制”是额外的 Key 上限，不是给周卡充值；留空或 0 表示不额外限制，仍受周卡剩余额度和有效期限制。

## 续卡与取消

- **续卡**：回到用户行的“管理 Claude 周卡”，处理方式选 **排期续卡**，填写下一期额度，预览后确认。新卡从现有排期结束后生效；当前卡耗尽不会因提前续卡而立即补满。
- **查看余额**：管理员可重新打开同一用户的周卡弹窗；用户看“我的订阅”。用量结算中时以页面的“已知待结算费用”和提示为准。
- **取消**：在管理弹窗的“周卡历史”找到目标卡，点击 **取消周卡** 并填写原因。取消使用权与支付退款是不同操作。

## 常见卡点

- **分组下拉为空**：先关闭旧弹窗并刷新页面，再打开。正常应能看到“Claude 周卡 · 独立额度”。若仍为空，属于分组状态或配置故障，不是需要充值普通余额。
- **已开卡但客户端不可用**：检查客户端是否用了绑定新分组的 Key；确认 Key 没有停用或到期，周卡仍在有效期且有剩余。
- **提示已有卡期或排期变化**：已有卡使用“排期续卡”；重新预览并核对最新排期，不要连续重复点确认。
- **模型不可用**：使用页面列出的支持模型。新组沿用现有 Claude 上游的 20 个模型白名单，不提供 Fable。
