## 本次兼容处理

1. **Seedance 拼车边界**：新异步视频协议没有持久化创建时的拼车准入与周期，拼车 Key 提前返回 `403 CARPOOL_SEEDANCE_UNSUPPORTED`，避免已产生上游费用后无法可靠结算。普通 Key 保留上游的创建、查询、删除、任务归属和去重计费功能。标准分组中的拼车绑定用户也通过鉴权投影受到保护。
2. **批量编辑 Key**：选中拼车 Key 时，分组保持管理员分配的只读状态；仍可批量修改其他字段，并排除拼车目标组。此次不改变既有单 Key API 的授权语义。
3. **审计覆盖**：把路由覆盖盘点从源码正则改为真实 Gin 路由表，纳入循环注册的 Seedance 别名；四种入口均验证多段提示词被审计，阻断后不调用上游。Sentinel refresh 的严格元数据控制接口明确分类为无用户提示词。
