## P2 监控与复核

- [ ] 复核状态与 expected_review_version，服务端权限、同步管理审计、并发冲突与误判纠正。（R08）
- [ ] 站内持久告警、阈值版本、每事件贡献去重、恢复事件排除、窗口合并、管理员确认。（R07）
- [ ] 加密/持久化/审核不可用等运行告警，与用户风险告警分开。（R07）
- [ ] 如业务选择外部通道，再接持久通知任务、目标配置和重试；默认不开启、不发送提示词原文。（R07）

## P3 真实效果与灰度验收

- [ ] 每种语言盲测至少 1000 条正常样本和 200 条明确禁止样本；另设疑似、引用、越狱、混合语言等边界集。争议样本不混入确定违规召回率分母。（R10）
- [ ] 建议门槛：中英文各自正常误拦率 <= 1%，明确禁止召回率 >= 95%；同时报告分子/分母与 95% 置信区间。不同规则及长度分桶分别报告，不能用总体 accuracy 代替。（R10）
- [ ] 每条拟启用 block 规则、每种目标语言另需至少 100 条明确命中样本及 1000 条相关正常/边界阴性样本（可与总体集重叠），独立达到召回 >= 95%、误拦 <= 1%；不足或失败的规则只能保留观察，不随总体指标一起启用。越狱规则单独验收。（R01、R10）
- [ ] 召回只计该规则产生的 policy_blocked/attack_blocked；503/400/413 不算检出。正常请求受系统故障/覆盖限制/超限影响的比例另报端到端拒绝率与可用性，不能藏在低误拦率里。（R02、R10）
- [ ] 冻结关键必放/必拦工程回归样本必须全部通过；模型不稳定的样本单列，重试次数与结果分布不能隐藏。（R01、R10）
- [ ] 实测正常编程/逆向/求助等子集、短/中/长文本延迟与吞吐、首写/最终事务成本、恢复与告警积压。（R04、R10）
- [ ] 专用真实 Guard + mock 业务上游完成端到端证明；模拟 Guard 只能验证工程流程，不能给出模型准确率结论。（R02、R10）
- [ ] 后续正式部署授权后，先完成隔离环境同一 strict 策略重放，再对指定分组做阻断试点并逐步扩量；本版无线上 shadow，legacy async 观察结果不能替代 strict 验收。每一步保存配置版本、样本量和失败/误判报告。（R09、R10）
- [ ] 演练版本回滚、审核节点故障、数据库恢复与密钥备份恢复；全程不把静默放行作为自动降级。（R04、R09）

退出：全部 R01-R10 均有可复查证据。样本不足、模型不可达、Docker 不可用或网络隔离时明确标记未验证，不按通过处理。

## 核心验收矩阵

| ID | 场景 | 必查结果 | 需求 |
| --- | --- | --- | --- |
| A01 | 合法 system 指令、修改上一条需求、授权逆向 | 不因词面自动拦截或处罚 | R01、R10 |
| A02 | 引用攻击论文、自己的邮箱、自伤求助 | 保留上下文；疑似与明确违规区别 | R01、R10 |
| A03 | 明确内容/攻击禁止规则 | 403、持久事件、认证用户名；业务上游/扣费/任务创建零调用 | R01-R05 |
| A04 | 审核前数据库不可用 | 503、不调用业务上游、不承诺已保存原文 | R02、R04 |
| A05 | 已接纳后 Guard 超时/429/非法返回 | 503、可恢复输入、系统故障、不累计违规 | R01、R04 |
| A06 | Guard Allow/Block 后最终事务失败 | 均不转发；保留接纳记录；恢复标 re_evaluated | R02、R04 |
| A07 | 首写后强制结束进程/客户端取消 | 新 worker 租约恢复；不重放原请求；迟到 owner 无法覆盖 | R04 |
| A08 | 两实例同时恢复/重复通知消费 | 最终事件唯一、计数唯一、通知去重边界明确 | R04、R07 |
| A08b | 已提交 503 后恢复发现风险、原最终事务未提交 | 原响应意图分别为 503/unknown，恢复结果单列，不冒充实时阻断 | R04、R07 |
| A09 | 文本超过 65536 字符、首中末危险片段、跨分片语义 | 完整证据或明确超限；不静默截断；全片成功才准许通过 | R05、R10 |
| A10 | 用户改名/删除/API Key 删除/伪造请求体身份 | 保持原身份快照，过滤和聚合不串用户 | R03 |
| A11 | 普通用户查看、无访问审计、解密失败、过期、读取/删除并发 | 不返回未授权明文；删除先提交不再授权读取；普通详情不携带原文 | R06 |
| A12 | 清理/删除与 worker 并发、历史一 job 多事件、迁移中断 | 不复活已删除证据；每事件原文不串；迁移可续跑，旧未知角色不猜测 | R04-R06 |
| A13 | SSE 等待审核、WS 第二轮、媒体异步提交 | 不提前写成功流/发送帧/创建业务任务 | R02、R09 |
| A14 | 模型仅声称支持/纯媒体/远端历史引用 | 精确标识 text_only/not_inspected，不声称全输入安全 | R05、R09 |
| A14b | 正常 user 文本 + 工具返回/参数内危险文本 | 所有声明字段被解析检查；不支持内容类型不能因有正常文本就被掩盖 | R05、R09 |
| A15 | 误判复核、并发复核、重复阻断阈值 | 原判定保留、冲突 409、风险计数正确、告警可定位 | R07、R08 |
| A16 | 默认升级/混合版本/开关关闭/回滚 | 未启用流量无变化，严格流量不被旧版本无意放行 | R09 |
| A16b | 未配置密钥的 legacy 升级、全局保护开关、遗留 writer | 准备阶段兼容；不满足全节点条件不能启用加密/严格模式；启用后不回退明文 | R06、R09 |

## 预计修改面

核心为 `backend/internal/securityaudit/`，薄接线在已有 handler/helper；旧审核仅提取评估边界，不做整文件顺手重构。数据库用 `backend/migrations/` 的新 migration；加密配置和审计同步记录限定为必要公共接口扩展。前端集中 `frontend/src/features/prompt-audit/` 与对应 locale/types/routes。

`backend/internal/server/routes/admin.go` 当前含无关未提交变更；修改前读取最新差异，只调整本功能对应路由。规格更新保留旧 change 历史，用新增版本说明替换失真的“原文不入库”当前契约。
