## 审查时必须拿到的逐表证据

对于同一合成用户，同时保存 GPT 和 Claude 请求前后的：普通余额与冻结额、GPT term/cycle/ledger、Claude term/request/ledger、原生日周月使用量、各自 Key 计数和 usage_logs。用相同精度计算差额。

Claude 结算允许改变自己的卡期与请求、专用 ledger、该 Key 使用计数及实际账号统计。对普通余额、GPT 业务表、原生窗口用量和其他用户卡期的增量必须严格为零。GPT 请求反向验证 Claude 表严格零变化。

单纯返回 HTTP 200、group_id 显示正确或 API 返回剩余金额，均不能替代这份账务证据。
